# Inteligência Artificial
 
## Sobre o Repositório
 
Este repositório foi criado para armazenar os notebooks e atividades desenvolvidos durante a disciplina de Inteligência Artificial.
 
## Objetivo
 
Organizar e disponibilizar as atividades realizadas durante a disciplina, mantendo os notebooks e seus respectivos exercícios em um único local.
 
## Conteúdo do Repositório
 
## Lista de Exercícios de Python
 
O notebook `lista_exercicios_python.ipynb` contém uma lista com 50 exercícios de programação em Python.
 
Os exercícios trabalham conteúdos como:
 
* Variáveis e entrada de dados;
* Operações matemáticas;
* Estruturas condicionais;
* Estruturas de repetição;
* Listas;
* Strings;
* Dicionários;
* Funções;
* Recursividade;
* Algoritmos de ordenação;
* Busca binária;
* Sequência de Fibonacci;
* Jogos simples;
* Manipulação de dados;
* Gráficos com Matplotlib.
